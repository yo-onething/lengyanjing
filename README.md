# 楞严经共读 · 陪读笔记

每天一篇、5 分钟可读完的《楞严经》白话陪读。从 2026-10-19 开始，每晚一篇。

- 不堆佛学术语，第一次出现的术语都用一句话解释
- 每篇只讲一个小节：背景一句话 / 今天讲什么 / 白话拆解 / 记住一句话 / 明日预告
- 总地图：破（七处征心）→ 立（十番显见、如来藏）→ 行（四种清净明诲、二十五圆通）→ 防（五十阴魔）
