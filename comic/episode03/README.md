# 第三话《十番显见》

佛陀带阿难亲眼看见"见性"：十番开示，一番比一番深。

| 格 | 内容 |
|---|---|
| p01 | 开场：承接"不知道就对了"；憍陈那长老插格："不住的是客，住下的是主；摇动的是尘，澄寂的是空" |
| p02 | 第一番·显见是心：佛陀举金色光明拳；盲人插格——盲人无眼尚能见暗，见何曾亏过 |
| p03 | 第二番·显见不动：佛手开合、阿难随宝光回头——动的是手是头，见可曾动过 |
| p04 | 第三番·显见不灭：波斯匿王观恒河——三岁看恒河与六十二岁看恒河，水一样；汝面虽皱，见精性未曾皱 |
| p05 | 第四番·显见不失：见明见暗，见非明暗；见见之时，见非是见——阿难：越听越糊涂了 |
| p06 | 第五番·显见无还：以指指月；明还日、暗还月、通还门窗、塞还墙壁；见精如第二月 |
| p07 | 第六番·显见不杂：阿难遍观日月山川——物有千万种，看的那一个从没变过 |
| p08 | 第七番·显见无碍 + 第八番·显见不分：指皆是物，无是见者；指不出，就对了——它不是物 |
| p09 | 第九番·显见超情 + 第十番·显见离见：阿难悲泪顶礼；下一话《四科七大》 |
