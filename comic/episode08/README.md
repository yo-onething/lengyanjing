# 第八话《五十阴魔·上》

修行路上的第一针疫苗：色阴、受阴、想阴三十魔——觉得自己修出本事了，恰恰是第一关没过。

| 格 | 内容 |
|---|---|
| p01 | 开场：承接第七话，总地图最后一站——"防"；佛陀："修行的方法，都给你了。出发之前，先打一针疫苗" |
| p02 | 色阴·其一：修行人打坐发光，眼前雾中一扇门——"咦……我好像，能穿墙了？"；禅定越深，幻觉越真 |
| p03 | 色阴·其二：主观视角——暗室一束柔光，雾中浮现佛国幻影；穿墙、发光、看见佛国，全是"看起来像神通"的东西 |
| p04 | 色阴·其三：修行人挺胸自得，影子拉得很长；佛陀："不作圣心，名善境界；若作圣解，即受群邪" |
| p05 | 受阴·其一：修行人独坐湖心，情绪如潮水层层涌来；受阴——情绪被突然放大，苦乐喜忧全在这一层 |
| p06 | 受阴·其二：水镜倒影——一张悲泣，一张欢喜；无缘无故悲从中来，又有人欢喜得停不下来，都是副作用 |
| p07 | 想阴·其一：念头像风中落叶与纸鹤纷纷飞舞；想阴的魔有个统一特征——"求" |
| p08 | 想阴·其二：伸手抓一道"顿悟"的光，光如雾在指尖散开；"抄近道"的心态本身就是漏洞 |
| p09 | 收束：佛陀与阿难并肩望向远方山路；情绪和念头再精彩，也只是疫苗说明书上的副作用名单；下一话《五十阴魔·下》 |
