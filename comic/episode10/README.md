# 第十话《全经收尾》

十九天前，阿难被问住；今天，整部经收成一张图：破→立→行→防。全系列收官。

| 格 | 内容 |
|---|---|
| p01 | 开场回扣：佛陀与阿难对坐，"阿难，心在哪里？"；左上小插格：摩登伽女与阿难（第一话开场） |
| p02 | 破·七处征心：七个答案一一拆掉——找得到位置的，都不是真心 |
| p03 | 立·十番显见与如来藏：能看见的那个本事，本身就是真心；世界不是真心造的，是真心打了个盹做的梦 |
