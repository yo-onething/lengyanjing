# 楞严经漫画 · 第一话《心在哪？》

画风：龙猫/吉卜力式简洁风。配字原则：文字不挡脸。

## 分镜

| 格 | 内容 |
|---|---|
| p01 | 祇园精舍开场。佛陀讲法，阿难持钵，"今天轮到我进城托钵……" |
| p02 | 街头相遇。摩登伽女看见阿难："这世上……怎么有这么好看的人？" |
| p03 | 阿难主观视角：世界旋转，钵滑落。 |
| p04 | 房中危机。阿难"不……不行……"，心里还剩最后一丝清明。 |
| p05 | 佛陀停下讲法："阿难有难。" |
| p06 | 文殊菩萨持火焰智慧剑，踏云而来。 |
| p07 | 文殊持咒：金色咒轮如日当空，阿难在光中睁眼："我……我这是在哪？！" |
| p08 | 佛前认错。阿难落泪："世尊，我错了……我连自己的心都守不住。" |
| p09 | 佛陀发问："你说'心'守不住——那我问你，你的'心'，到底在哪里？" |
| p10 | 双线钩子：阿难沉思/摩登伽女远望/佛陀微笑。下一话"七处征心"。 |
