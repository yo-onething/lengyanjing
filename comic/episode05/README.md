# 第五话《四种清净明诲》

阿难问"怎么修"，佛陀不急着给方法，先立四条底线——断淫、断杀、断盗、断妄，修行的地基工程。

| 格 | 内容 |
|---|---|
| p01 | 开场：阿难问"怎么修？"；佛陀："不急着给方法。先立四条底线。" |
| p02 | 总纲：四种清净明诲——修行的地基工程；水池四处漏水：地基漏着水，楼盖不高 |
| p03 | 断淫：僧人关木门，门外小火苗熄灭，窗内莲花开——心不被欲望牵着跑 |
| p04 | 断杀：拳头松开，小鸟飞向天空——不只是不杀生，深层是嗔恨 |
| p05 | 断盗：伸向枝头果子的手停住、收回——不只是不偷东西，深层是总想占便宜 |
| p06 | 断妄：赶路人持歪罗盘，远方正路通向朝阳——没修到说自己修到了，歪的是方向盘 |
| p07 | 蒸沙成饭：蒸锅里是沙，旁边一小碗白米——材料错了，功夫越深错得越离谱 |
| p08 | 先堵漏再修：阿难俯身堵住水池的四个漏口——先把漏堵上，修才修得上去 |
| p09 | 收束：佛陀与阿难并肩望朝阳；漏着水盖楼，盖不起来——下一话《耳根圆通》 |
