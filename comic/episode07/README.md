# 第七话《修行次第》

佛陀给阿难一张修行路线图：十信、十住、十行、十回向、四加行、十地、等觉、妙觉——一站一站走，不靠一步到位。

| 格 | 内容 |
|---|---|
| p01 | 开场：承接耳根圆通，阿难追问修行可有先后次第；佛陀：有，而且是一张五十五个站点的地图 |
| p02 | 第一站·十信：山脚仰望——先"信"，相信这条路走得通、相信自己走得到；好比学做菜先得信"菜是能学会的" |
| p03 | 第二站·十住：山腰小屋安住——选定这条路就不再换赛道，不再今天学川菜、明天学烘焙 |
| p04 | 第三站·十行：山间切菜颠勺——动手"干"，把道理变成手上的功夫 |
| p05 | 第四站·十回向：山顶分菜给路人——功德"回转"出去利益众生；心量打开，是大乘和小乘的分水岭 |
| p06 | 大本营·四加行：暖、顶、忍、世第一法——登山前的大本营，适应高原反应；越往上越不能急 |
| p07 | 第五站·十地：云梯拾级而上——从欢喜地初尝法喜，到法云地像云一样普覆一切；每上一层，烦恼薄一层 |
| p08 | 山顶·等觉、妙觉：登顶回望来路——理则顿悟，乘悟并销；事非顿除，因次第尽；明白道理是"信"，走完地图才是"证" |
| p09 | 收束：修行是一张可以一站一站走的地图，不靠一步到位；下一话《五十阴魔·上》：路上有魔，先打疫苗 |
