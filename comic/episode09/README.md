# 第九话《五十阴魔·下》

行阴、识阴二十魔收官：再神奇的体验，也只是路边的风景——不作圣心，名善境界。

| 格 | 内容 |
|---|---|
| p01 | 开场：承接前话，佛陀与阿难对坐——色、受、想三关已过，剩下两关最微细；五十阴魔收官 |
| p02 | 行阴·流动：溪水浮叶生灭——行阴是心里念头生灭不停的那股"流动感" |
| p03 | 行阴·无因论：空中海市蜃楼——见万物似无来由，便断言"一切无因无缘"，把局部当全部 |
| p04 | 行阴·常与断：山路分岔，青山与断崖——或说万物恒常，或说死后断灭，都是拿一点点体验下宇宙级结论 |
| p05 | 识阴·清明灵觉：夜湖如镜，一盏清光——行阴看破，只剩一个清明灵觉 |
| p06 | 识阴·真我错觉：镜花水月，手捞月影碎成涟漪——把"我执"换了件衣服 |
| p07 | 总口诀：佛陀拈花微笑——"不作圣心，名善境界；若作圣解，即受群邪" |
| p08 | 路边风景：修行人行走山路不停步，奇光异花只淡淡一瞥——继续走，别停，别给自己发奖状 |
| p09 | 收束：佛陀与阿难并肩行于山道——"世尊，我记下了——不作圣心"；下一话《全经收尾》 |
