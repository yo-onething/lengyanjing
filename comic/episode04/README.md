# 第四话《四科七大》

富楼那追问：真心不生不灭，世界从哪来？佛陀答：不是真心造了世界，是真心上起了一念妄——"迷妄有虚空，依空立世界"；如来藏是不动的仓库，世界、众生、业果三部连续剧在它里面接力上演。

| 格 | 内容 |
|---|---|
| p01 | 开场：承接"接下来，我带你把这一切看遍——"；富楼那起身追问：见性不生不灭，山河大地、轮回生死从哪来？ |
| p02 | 一念妄起：心湖泛起涟漪——心本是觉，多此一念就是无明；"性觉必明，妄为明觉" |
| p03 | 虚空初现，世界层层立起："迷妄有虚空，依空立世界"；阿难心声：原来世界不是造出来的 |
| p04 | 做梦喻：梦里的山河人物，没从外面搬进来一砖一瓦——世界不是真心造的，是真心打了个盹做的梦 |
| p05 | 如来藏·仓库：世界、众生、业果全在它里面，仓库本身不动、不生、不灭 |
| p06 | 世界相续：风动生出金轮、水轮、地轮，世界一层层凝住；风扇不停，世界就不散 |
| p07 | 众生相续：想爱同结，一代接一代把棒递下去，队伍一直续下去 |
| p08 | 业果相续 + 四科七大：造业得果、果又推业，像滚雪球；五阴六入十二处十八界、地水火风空见识，一一皆是如来藏 |
| p09 | 收束：真心不动，妄想在里面接力；下一话《四种清净明诲》：修行先打地基 |
