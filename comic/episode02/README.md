# 第二话《七处征心》

佛陀连问七次，阿难连答七次，次次被破。

| 格 | 内容 |
|---|---|
| p01 | 开场：佛陀发问"你的心到底在哪里？" |
| p02 | 第一答：心在身体里面 → 破：先看见肚子里的心肝再说 |
| p03 | 第二答：心在身体外面 → 破：合掌时心怎么知道手合在一起了 |
| p04 | 第三答：心藏在眼睛里 → 破：眼睛若是心，怎么看不见自己 |
| p05 | 第四答：闭眼见暗就是在内 → 破：暗是外面的东西 |
| p06 | 第五答：哪有感觉心就在哪 → 破：没固定的东西怎么"跟着" |
| p07 | 第六答：在眼和东西中间 → 破：空的叫什么中间 |
| p08 | 第七答：什么都不执著的就是心 → 破：连心都没有了还叫心吗；阿难认输 |
| p09 | 收束："不知道，就对了。"下一话《十番显见》 |
