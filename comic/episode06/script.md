# 楞严漫画 · 第六话《耳根圆通》分镜脚本

> 对应晚读 Day 13–14：二十五圆通总说 + 观世音耳根圆通 + 文殊拣选。
> 画风要求（用户原话）："画面优雅一些别乱画"——吉卜力简洁风，优雅干净留白，不堆细节。
> 配字铁律：旁白/气泡/心声一律避开人物脸部；气泡尾巴不得穿过他人头部。
> 压缩说明：9 格——第 1 格承接第五话（地基打好，给方法），第 2–3 格二十五圆通总说，第 4–6 格观世音耳根圆通，第 7–8 格文殊拣选，第 9 格收束+钩子。

| 格 | 画面 | 台词 |
|---|---|---|
| 1 | 承接第五话：佛陀与阿难对坐，晨光熹微，大片留白；远处众圣者身影 | 佛陀："地基打好了。接下来，我给你们方法。" / 旁白（小字）："佛陀问：在座修成的各位，你们当初是从哪个门进来的？" |
| 2 | 二十五位圣者轮流发言：众人环坐，六根六尘六识七大小示意（眼耳鼻舌身意小图标环绕） | 旁白："六根、六尘、六识、七大，各出一人——二十五条路，条条到顶。" / 阿难（心声）："二十五条路？哪一条才顺手？" |
| 3 | 观世音菩萨出场：白衣观音持杨柳枝与净瓶，众圣者让出一条路，晨光落在她身上 | 观音："我从耳根入。反闻闻自性。" / 旁白（小字）："二十五人中，观世音讲的是耳朵这条路。" |
| 4 | 反闻与顺闻对照：左侧一人被声音牵走（八卦、笑声化作细线缠住他），右侧观音端坐、声音从耳边轻轻滑过 | 观音："顺闻，是跟着声音跑；反闻，是收回来，落在'能听'本身。" / 旁白（小字）："声音照样进耳朵，注意力不追声音。" |
| 5 | 观音静坐入定：声波纹路在她耳边渐渐散开、化作清水；她眉目低垂，澄然 | 观音："初于闻中，入流亡所。" / 旁白（小字）："连'所听的声音'都忘了，只剩听本身澄澄湛湛。" |
| 6 | 十方圆明：观音端坐中央，四面八方淡淡的声纹环绕却近不得身，留白如清水 | 旁白："练久了，十方圆明——四面八方都清楚，却没有一个声音能拽走你。" |
| 7 | 文殊拣选：佛陀请文殊当评委，文殊持剑端坐，众人望向他 | 佛陀："文殊，你来评一评——哪一门，最适合这个世界？" / 文殊："二十五门，门门都通。选课，要看考场。" |
| 8 | 文殊说耳根三层理：闭目之人仍侧耳倾听；雷声起落，动静二相 | 文殊："眼睛一闭就看不见，耳朵可闭不上——睡着了还听得见。" / 文殊："此方真教体，清净在音闻。" / 旁白（小字）："动静二相，了然不生——内容换了，能听的那个一直在。" |
| 9 | 收束：文殊与观音并立，佛陀颔首微笑；远景大片留白，朝阳初升 | 文殊："十方如来同一道故，出离生死，皆以直心。" / 旁白（钩子）："下一话《修行次第》：一张可以一站一站走的地图。" |

## 出处备查
- 二十五圆通：六根（眼耳鼻舌身意）、六尘（色声香味触法）、六识、七大（地水火风空见识）各修通一门（《楞严经》卷五–卷六，二十五圣各述圆通）。
- 引文："反闻闻自性"；"初于闻中，入流亡所"；"十方圆明"；"此方真教体，清净在音闻"；"动静二相，了然不生"；"十方如来同一道故，出离生死，皆以直心"（《楞严经》卷六，观世音耳根圆通章与文殊拣选章）。
- 记住一句话（Day 13）："耳朵照常听，注意力不粘声音、收回落在听本身"；记住一句话（Day 14）："修行要选顺手的门，耳朵的门最顺这个世界"。
