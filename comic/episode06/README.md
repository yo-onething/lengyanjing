# 第六话《耳根圆通》

地基打好，给方法——二十五位圣者各讲一门，观世音走耳朵这条路；文殊拣选：耳根最顺这个世界。

| 格 | 内容 |
|---|---|
| p01 | 开场：地基打好，给方法；佛陀问：在座修成的各位，你们当初是从哪个门进来的？ |
| p02 | 二十五圆通总说：六根六尘六识七大，各出一人——二十五条路，条条到顶；阿难：哪一条才顺手？ |
| p03 | 观世音出场：我从耳根入。反闻闻自性 |
| p04 | 顺闻与反闻：顺闻是跟着声音跑；反闻是收回来，落在"能听"本身——声音照样进耳朵，注意力不追声音 |
| p05 | 初于闻中，入流亡所——连"所听的声音"都忘了，只剩听本身澄澄湛湛 |
| p06 | 十方圆明：四面八方都清楚，却没有一个声音能拽走你 |
| p07 | 文殊拣选：佛陀请文殊当评委——二十五门，门门都通。选课，要看考场 |
| p08 | 耳根最顺：眼睛一闭就看不见，耳朵可闭不上——睡着了还听得见；此方真教体，清净在音闻；动静二相，了然不生 |
| p09 | 收束：十方如来同一道故，出离生死，皆以直心；下一话《修行次第》 |
